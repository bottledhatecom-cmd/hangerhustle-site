# hangerhustle-site

Landing page for **Hanger Hustle** at https://hangerhustle.com (the app itself lives at https://app.hangerhustle.com/).

Plain static site served by GitHub Pages from `main` (root). No build step: edit `index.html` / `style.css`, push, done.
Android APKs are attached to this repo's GitHub Releases; update the download links in `index.html` when a new version ships.
Grow this page as the app grows: only list features that actually exist, and keep "coming soon" items labeled as coming.
